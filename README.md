# Zepto Inventory Analysis SQL Project

## Project Overview

This project analyzes Zepto inventory data using SQL to uncover valuable business insights related to product pricing, discounts, stock availability, inventory value, and revenue potential.

The analysis demonstrates practical SQL skills including data cleaning, filtering, aggregations, grouping, CASE statements, and business intelligence reporting using real-world inventory data.

---

## Database Schema

The project consists of a single inventory table:

### zepto

Stores product and inventory information.

| Column                 | Description                  |
| ---------------------- | ---------------------------- |
| sku_id                 | Unique product identifier    |
| category               | Product category             |
| name                   | Product name                 |
| mrp                    | Maximum Retail Price         |
| discountPercent        | Discount percentage offered  |
| availableQuantity      | Available stock quantity     |
| discountedSellingPrice | Selling price after discount |
| weightInGms            | Product weight in grams      |
| outOfStock             | Product stock status         |
| quantity               | Product quantity             |
